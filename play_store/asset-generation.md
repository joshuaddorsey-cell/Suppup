# Suppup Play Store asset generation

## Feature graphic

The base artwork was created with the built-in image generator using the
existing Suppup puppy logo and bone/paw background as visual references. It was
then mechanically sized to the required 1024 × 500 pixels and given
deterministic brand typography.

### Final generation prompt

```text
Use case: ads-marketing
Asset type: Google Play Store feature graphic, very wide 2.05:1 landscape composition
Primary request: Create a polished Suppup promotional banner using the same cheerful golden retriever puppy identity and soft dog-bone-and-paw visual language as the reference images.
Input images: Image 1 is the brand puppy and style reference; Image 2 is the background pattern and palette reference.
Scene/backdrop: Warm sunny neighborhood park walking path with soft green trees, subtle cream haze, and a few understated coral paw prints and pale sage dog bones integrated decoratively.
Subject: One happy golden retriever puppy on a blue leash walking toward the viewer, positioned entirely in the right 42% of the image.
Style/medium: High-end friendly 3D storybook illustration matching the existing Suppup puppy.
Composition/framing: Extremely wide banner; keep the left 52% calm, uncluttered, and light enough for dark-green marketing copy; no important details near edges.
Lighting/mood: Bright, warm, welcoming, safe, playful.
Color palette: Cream, deep forest green, sage, coral, golden yellow, blue leash.
Constraints: Preserve the puppy's recognizable golden fur, big friendly eyes, blue collar and leash; exactly one dog; no text, no letters, no logos, no watermark; no UI mockup; no phones; no extra animals.
Avoid: busy background, photorealism, dark shadows, cropped face, duplicated limbs, distorted paws.
```
